# 计算属性（Calculated Fields）使用说明

## 概述

计算属性是平台中一个强大的功能，允许您基于设备、资产或其他实体的现有属性和遥测数据，通过数学表达式或脚本来创建派生数据。计算属性支持实时数据处理，能够自动计算并存储新的属性值或时序数据。

## 功能特点

- **实时计算**：基于输入数据变化自动触发重新计算
- **灵活的数据源**：支持设备、资产、客户、租户等多种实体类型作为数据源
- **多种输出类型**：支持输出为属性（服务器/共享属性）或时序数据
- **两种计算模式**：简单表达式和复杂脚本函数
- **导入导出**：支持计算属性配置的导入和导出

## 创建计算属性

### 基本配置

1. **名称**：为计算属性指定一个描述性名称（最大255字符）
2. **类型**：选择计算类型
   - **简单**：使用数学表达式进行计算
   - **脚本**：使用TBEL脚本语言编写复杂计算逻辑

### 参数配置

参数是计算属性的输入数据源，您需要配置：

#### 参数基本信息
- **参数名称**：在表达式中引用的变量名（不超过256字符）
- **数据源类型**：
  - 当前实体：使用当前实体的数据
  - 设备：指定设备作为数据源
  - 资产：指定资产作为数据源
  - 客户：指定客户作为数据源
  - 当前租户：使用租户级别的数据

#### 参数数据类型
- **属性**：使用实体的属性值
  - 服务器属性
  - 客户端属性
  - 共享属性
- **最新遥测**：使用最新的遥测数据值
- **时间序列滚动**：使用指定时间窗口内的历史数据序列
- **设备名称**：获取设备的名称
- **客户名称**：获取客户的名称
- **资产名称**：获取资产的名称

#### 时间序列滚动配置
当选择时间序列滚动类型时，需要配置：
- **时间窗口**：数据采集的时间范围
- **最大值限制**：返回数据点的最大数量
- **默认值**：当无数据时使用的默认值

### 表达式/脚本配置

#### 简单表达式
适用于直接的数学运算，例如：
```
(temperature - 32) / 1.8
```
支持的数学运算：
- 基本运算：+、-、*、/
- 数学函数：sqrt、sin、cos、log等
- 条件判断：三元运算符等

#### TBEL脚本
用于复杂的计算逻辑，脚本函数格式：
```javascript
function calculate(ctx, arg1, arg2, ...) {
    // 计算逻辑
    return result;
}
```

其中：
- `ctx`：上下文对象，包含元数据信息
- `arg1, arg2, ...`：配置的参数值
- 支持完整的JavaScript语法

### 输出配置

#### 输出类型
- **属性**：将计算结果保存为实体属性
  - 服务器属性：仅服务器可见的属性
  - 共享属性：可在设备和服务器间共享的属性
- **时序数据**：将计算结果保存为时序数据点

#### 简单类型输出配置
- **键名称**：属性键或时序键的名称
- **默认小数位数**：数值结果的小数位数
- **使用最新时序数据**：（仅时序输出）是否使用触发计算的数据的时间戳

## 使用场景示例

### 1. 温度单位转换
将华氏度转换为摄氏度：
- **参数**：`fahrenheit`（设备的温度遥测数据）
- **表达式**：`(fahrenheit - 32) / 1.8`
- **输出**：时序数据，键名为`celsius`

### 2. 能耗统计
计算设备功耗：
- **参数**：
  - `voltage`（电压遥测）
  - `current`（电流遥测）
- **表达式**：`voltage * current`
- **输出**：时序数据，键名为`power`

### 3. 状态判断
基于多个传感器数值判断设备状态：
- **参数**：
  - `temperature`（温度）
  - `humidity`（湿度）
  - `pressure`（压力）
- **脚本**：
```javascript
function calculate(ctx, temperature, humidity, pressure) {
    if (temperature > 30 && humidity > 80) {
        return "HIGH_RISK";
    } else if (temperature > 25 && humidity > 60) {
        return "MEDIUM_RISK";
    } else {
        return "NORMAL";
    }
}
```
- **输出**：共享属性，键名为`status`

### 4. 历史数据分析
计算过去1小时的平均值：
- **参数**：`values`（时间序列滚动，1小时窗口）
- **脚本**：
```javascript
function calculate(ctx, values) {
    if (!values || values.length === 0) {
        return 0;
    }

    var sum = 0;
    for (var i = 0; i < values.length; i++) {
        sum += values[i].value;
    }

    return sum / values.length;
}
```
- **输出**：时序数据，键名为`hourly_average`

## 管理功能

### 导入导出
- **导出**：可将计算属性配置导出为JSON文件
- **导入**：可从JSON文件导入计算属性配置，系统会自动调整实体引用

### 脚本测试
在脚本模式下，提供测试功能：
- 可以模拟输入参数值
- 实时查看计算结果
- 验证脚本逻辑正确性

## 注意事项

1. **性能考虑**：
   - 时间序列滚动参数会占用更多计算资源
   - 建议合理设置时间窗口和数据点限制

2. **数据类型兼容**：
   - 确保参数数据类型与表达式兼容
   - 处理可能的空值或无效值情况

3. **权限限制**：
   - 计算属性的执行权限继承自创建者
   - 跨实体访问需要相应的数据访问权限

4. **更新频率**：
   - 计算属性在参数数据更新时自动触发
   - 高频更新可能影响系统性能

5. **错误处理**：
   - 脚本中应包含适当的错误处理逻辑
   - 避免未捕获的异常导致计算失败

## 最佳实践

1. **命名规范**：使用清晰、描述性的名称
2. **参数验证**：在脚本中验证输入参数的有效性
3. **性能优化**：避免不必要的复杂计算
4. **测试验证**：使用测试功能验证计算逻辑
5. **文档记录**：为复杂的计算逻辑添加注释说明

通过合理使用计算属性功能，您可以实现数据的实时处理和转换，为业务决策提供更有价值的派生数据。
