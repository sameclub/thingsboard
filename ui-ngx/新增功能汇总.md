# 新增功能汇总（基于 luming-v1 分支）

## 一、设备遥测图表功能

**功能说明**: 在设备详情页新增"遥测图表"页签，自动为每个遥测键生成实时图表。

**新增文件**:
- `src/app/modules/home/pages/device/device-telemetry-charts.component.ts`
- `src/app/modules/home/pages/device/device-telemetry-charts.component.html`
- `src/app/modules/home/pages/device/device-telemetry-charts.component.scss`

**集成位置**:
- 页签: `src/app/modules/home/pages/device/device-tabs.component.html:35`
- 模块: `src/app/modules/home/pages/device/device.module.ts`

**特性**: 实时显示最近1小时数据，1秒刷新，每行2个图表。
