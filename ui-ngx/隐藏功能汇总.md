## 总结

### 隐藏功能统计
- **用户管理**: 客户用户登录禁用、遥测部件显示按钮隐藏
- **菜单导航**: 8+ 个主要菜单项隐藏、面包屑导航跳过
- **设备功能**: 多处列表、详情与向导简化
- **计算属性**: 脚本模式、调试功能、多实体数据源选择隐藏
- **系统设置**: 通知、队列、语言设置、JWT Token等
- **UI 元素**: 50+ 个帮助按钮与品牌相关元素
- **协议支持**: 局部隐藏 LwM2M、SNMP、X.509 证书认证

### 新增功能统计
- **设备遥测图表**: 新增专门的遥测数据可视化页签
- **品牌定制**: 应用标题和图标的定制化支持
- **国际化增强**: 中文本地化改进

### 实现方式总结
1. **HTML注释**: 大部分UI元素通过 `<!-- -->` 注释隐藏
2. **代码注释**: TypeScript代码中的逻辑通过 `//` 或 `/* */` 注释
3. **条件隐藏**: 使用Angular的结构指令如 `*ngIf="false"` 或 `[class.hidden]="true"`
4. **配置调整**: 修改环境变量、路由配置等
5. **数组过滤**: 移除不需要的菜单项、选项等

### 恢复建议
所有隐藏均以注释或可配置方式完成，可按需恢复：
1. **快速恢复**: 取消HTML/代码注释
2. **条件恢复**: 修改显示条件或配置项
3. **选择性恢复**: 根据业务需求恢复特定功能
4. **测试验证**: 恢复后需要进行功能测试确保正常工作

### 维护说明
- 隐藏功能的代码仍然保留，便于后续恢复或维护
- 所有修改都有明确的注释说明原因和恢复方法
- 国际化文本保持完整，支持多语言切换
- 新增功能与隐藏功能相互独立，不影响系统稳定性
