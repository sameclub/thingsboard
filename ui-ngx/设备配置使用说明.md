# 设备配置使用说明

## 概述

本文档详细介绍设备配置的具体操作步骤，包括设备配置文件创建、传输协议配置和设备凭据管理。文档基于当前系统实际可用功能编写。

## 1. 创建设备配置文件

### 1.1 打开设备配置文件创建向导

1. 登录管理界面
2. 在左侧菜单中选择"设备配置文件"
3. 点击右上角"+"按钮或"添加设备配置文件"按钮
4. 系统会打开设备配置文件创建向导

### 1.2 步骤 1：配置基本信息

#### 必填字段：
- **名称**: 输入设备配置文件的唯一名称（最多 255 个字符）
  - 示例: "温湿度传感器配置文件"
- **类型**: 选择"默认类型 (DEFAULT)"（当前唯一可用选项）

#### 可选字段：
- **描述**: 输入配置文件的详细说明
  - 示例: "用于温湿度传感器设备的标准配置"
- **图片**: 上传配置文件图标（可选）

#### 操作步骤：
1. 在"名称"字段输入配置文件名称
2. "类型"字段保持默认选择
3. 填写描述信息（建议填写以便后续管理）
4. 点击"下一步"按钮

### 1.3 步骤 2：配置传输协议

#### 可选的传输协议：
- **默认协议 (DEFAULT)**: HTTP/HTTPS 传输
- **MQTT 协议**: MQTT/MQTTS 传输
- **CoAP 协议**: CoAP/CoAPS 传输

#### 2.1 默认协议配置
1. 选择"默认 (DEFAULT)"传输类型
2. 系统自动应用默认配置
3. 无需额外配置参数
4. 适用于 HTTP/HTTPS 连接的设备

#### 2.2 MQTT 协议配置
1. 选择"MQTT"传输类型
2. 配置 MQTT 主题：
   - **设备遥测主题**: `v1/devices/me/telemetry`
   - **设备属性主题**: `v1/devices/me/attributes`
   - **设备属性订阅主题**: `v1/devices/me/attributes`
3. 负载类型配置：
   - 选择"JSON"或"Protobuf"格式
   - 建议初学者选择 JSON 格式
4. 高级设置（可选）：
   - Sparkplug 支持：保持默认关闭
   - 验证异常确认：保持默认关闭

#### 2.3 CoAP 协议配置
1. 选择"CoAP"传输类型
2. 设备类型配置：
   - 选择"默认类型"或"Efento 类型"
   - 一般选择"默认类型"
3. 负载类型：选择"JSON"格式
4. 客户端设置：
   - 功耗模式：选择"DRX"模式

#### 操作步骤：
1. 从下拉菜单选择所需的传输类型
2. 根据选择的协议填写相应参数
3. 检查配置参数是否正确
4. 点击"下一步"按钮

### 1.4 步骤 3：设备预配置

#### 预配置选项：
- **禁用**: 不允许自动创建新设备（推荐用于生产环境）
- **允许创建新设备**: 自动创建新连接的设备（适用于开发测试）
- **检查预配置设备**: 只允许预先配置的设备连接

#### 配置步骤：
1. 选择合适的预配置类型：
   - 生产环境：选择"禁用"
   - 开发环境：可选择"允许创建新设备"
2. 如选择"检查预配置设备"，需要配置：
   - 预配置设备密钥
   - 预配置设备密文
3. 点击"添加"按钮完成创建

## 2. 设备凭据配置

### 2.1 设备凭据概述

设备凭据用于验证设备身份，确保只有授权的设备能够连接到平台。根据传输协议不同，支持不同类型的凭据。

### 2.2 访问令牌凭据配置

#### 2.2.1 适用协议
- 默认协议 (DEFAULT)
- MQTT 协议
- CoAP 协议

注意：当前系统只支持访问令牌凭据类型，其他凭据类型已临时隐藏。

#### 2.2.2 配置步骤
1. **打开设备凭据页面**：
   - 在设备列表中选择要配置的设备
   - 点击设备名称进入设备详情页
   - 选择"凭据"选项卡

2. **选择凭据类型**：
   - 凭据类型选择"访问令牌 (Access Token)"
   - 这是最常用的认证方式

3. **配置访问令牌**：
   - **手动输入**：在"访问令牌"字段直接输入自定义令牌
   - **自动生成**：点击"生成"按钮系统自动生成令牌
   - **复制令牌**：点击复制按钮复制令牌用于设备配置

4. **保存配置**：
   - 检查令牌格式是否正确
   - 点击"保存"按钮保存凭据配置

#### 2.2.3 令牌使用示例
```
# HTTP 请求示例
curl -v -X POST -d '{"temperature":25}' \
http://localhost:8080/api/v1/YOUR_ACCESS_TOKEN/telemetry \
--header "Content-Type:application/json"

# MQTT 连接示例
mosquitto_pub -d -h localhost -p 1883 \
-t v1/devices/me/telemetry \
-u "YOUR_ACCESS_TOKEN" \
-m '{"temperature":25}'
```

### 2.3 凭据安全注意事项

- 访问令牌应保持机密，避免泄露
- 定期更换访问令牌提高安全性
- 在设备配置中正确使用凭据信息
- 为不同环境（开发、测试、生产）使用不同的凭据

## 3. 创建和配置设备

### 3.1 创建新设备

#### 3.1.1 基本设备创建
1. **打开设备创建页面**：
   - 在左侧菜单选择"设备"
   - 点击右上角"+"按钮

2. **填写设备基本信息**：
   - **设备名称**: 输入设备的唯一名称
     - 示例: "办公室温湿度传感器-001"
   - **设备标签**: 输入设备标签（可选）
     - 示例: "温湿度传感器"
   - **设备配置文件**: 选择之前创建的设备配置文件

3. **分配设备到客户**（可选）：
   - 如果是租户管理员，可以选择将设备分配给特定客户
   - 如果是客户用户，设备会自动分配给当前客户

4. **完成创建**：
   - 检查信息填写完整
   - 点击"添加"按钮创建设备

### 3.2 设备传输配置

#### 3.2.1 默认协议设备配置
默认协议设备无需额外的传输配置，直接使用设备凭据即可连接。

#### 3.2.2 MQTT 设备配置
MQTT 设备通常继承配置文件的设置，无需额外配置。

#### 3.2.3 CoAP 设备配置
1. **进入设备配置页面**：
   - 在设备详情页选择"配置"选项卡

2. **配置传输参数**：
   - **功耗模式**: 选择合适的功耗模式（通常为 DRX）
   - **eDRX 周期**: 设置扩展不连续接收周期（可选）
   - **寻呼传输窗口**: 设置寻呼传输时间窗口（可选）
   - **PSM 活动计时器**: 设置省电模式活动计时器（可选）

3. **保存配置**：
   - 确认参数设置合理
   - 点击"保存"按钮

## 4. 设备连接验证

### 4.1 连接测试步骤

#### 4.1.1 HTTP/HTTPS 连接测试
```bash
# 发送遥测数据测试
curl -v -X POST -d '{"temperature":25,"humidity":60}' \
http://your-host:8080/api/v1/YOUR_ACCESS_TOKEN/telemetry \
--header "Content-Type:application/json"

# 发送属性数据测试
curl -v -X POST -d '{"firmware_version":"1.0.1"}' \
http://your-host:8080/api/v1/YOUR_ACCESS_TOKEN/attributes \
--header "Content-Type:application/json"
```

#### 4.1.2 MQTT 连接测试
```bash
# 发送遥测数据
mosquitto_pub -d -h your-host -p 1883 \
-t v1/devices/me/telemetry \
-u "YOUR_ACCESS_TOKEN" \
-m '{"temperature":25,"humidity":60}'

# 发送属性数据
mosquitto_pub -d -h your-host -p 1883 \
-t v1/devices/me/attributes \
-u "YOUR_ACCESS_TOKEN" \
-m '{"firmware_version":"1.0.1"}'
```

#### 4.1.3 CoAP 连接测试
```bash
# 发送遥测数据（需要 coap-client 工具）
echo '{"temperature":25}' | coap-client -m post \
coap://your-host:5683/api/v1/YOUR_ACCESS_TOKEN/telemetry
```

### 4.2 验证连接成功

1. **查看设备状态**：
   - 在设备列表中查看设备状态
   - 成功连接的设备状态显示为"活跃"

2. **查看最新遥测数据**：
   - 进入设备详情页
   - 选择"最新遥测"选项卡
   - 检查是否收到最新的数据

3. **查看设备日志**：
   - 选择"事件"选项卡
   - 查看设备连接和数据传输日志

## 5. 常见问题解决

### 5.1 设备无法连接

#### 5.1.1 检查凭据配置
- 验证访问令牌是否正确
- 确认令牌没有多余的空格或特殊字符
- 重新生成令牌进行测试

#### 5.1.2 检查网络连接
- 确认设备能够访问服务器
- 检查防火墙设置是否阻止连接
- 验证端口是否正确开放

#### 5.1.3 检查协议配置
- 确认设备使用的协议与配置文件一致
- 验证主题配置是否正确（MQTT）
- 检查 URL 路径是否正确（HTTP/CoAP）

### 5.2 数据无法上传

#### 5.2.1 检查数据格式
- 确认数据格式为有效的 JSON
- 检查字段名称和数据类型
- 验证数据大小是否超过限制

#### 5.2.2 检查主题配置
- MQTT 设备检查主题路径是否正确
- 确认遥测和属性主题的区别
- 验证主题权限设置

### 5.3 认证失败

#### 5.3.1 令牌问题
- 重新生成访问令牌
- 检查令牌是否过期
- 确认设备使用的令牌与平台配置一致

#### 5.3.2 设备状态
- 检查设备是否被禁用
- 确认设备配置文件是否正确分配
- 验证客户分配是否正确

## 6. 最佳实践建议

### 6.1 配置文件管理
- 为不同类型的设备创建专门的配置文件
- 使用描述性的配置文件名称
- 定期审查和更新配置文件

### 6.2 凭据安全
- 定期更换访问令牌
- 避免在代码中硬编码令牌
- 使用环境变量存储敏感信息

### 6.3 设备命名
- 使用有意义的设备名称
- 包含位置或功能信息
- 建立命名规范便于管理

### 6.4 测试流程
- 在生产环境部署前进行充分测试
- 使用测试配置文件进行开发
- 验证所有功能正常工作后再上线
